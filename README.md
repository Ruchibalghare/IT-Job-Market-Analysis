# IT-Job-Market-Analysis
Data Analytics project analyzing IT job market trends using Python.


## Problem Statement
Analyze IT job listings to identify hiring trends, salary patterns, and in-demand skills.

## Dataset
Glassdoor IT Jobs Dataset (2253 job postings)

## Data Cleaning
- Removed unnecessary columns
- Handled missing values
- Extracted min, max, and average salary
- Removed invalid industry values

## Analysis Performed
- Top Job Roles
- Location-wise Hiring Trends
- Industry-wise Salary Comparison
- Python vs Java Demand
- Top Technical Skills Extraction
- Salary by Company Size

## Key Insights
- Data Analyst is most common role.
- IT Services is highest hiring industry.
- Python demand exceeds Java.
- Drug & Health Stores industry offers highest salary.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn
